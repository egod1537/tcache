# Tokyo outer private railway artifacts

This directory is reserved for immutable Challenge 2026 source artifacts for
Keikyu, Seibu, Tobu, and Sotetsu. Keisei remains blocked until an official,
train-level machine-readable source can be verified.

Downloaded source bytes are local personal education/research artifacts. They
must not be redistributed or used commercially. `ODPT_CHALLENGE_KEY` is never
stored in manifests or logs.
